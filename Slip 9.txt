Q1) Write a program to read the contents of “abc.txt” file. Display the 
contents of file in uppercase as output.


class ReadFile
{
    public static void main(String args[]) throws Exception
    {
        FileReader fr = new FileReader("abc.txt");

        int ch;

        System.out.println("File Contents in Uppercase:");

        while((ch = fr.read()) != -1)
        {
            System.out.print(Character.toUpperCase((char)ch));
        }

        fr.close();
    }
}




Q2) Write a JavaScript program to store student information and marks in
variables and generate a formatted student report using template literals.
