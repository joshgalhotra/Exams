Q1) Write a Java program that defines an interface Calculator containing 
methods add() and subtract() and implements it in class SimpleCalc.


interface Calculator {
    void add(int a, int b);
    void subtract(int a, int b);
}

class SimpleCalc implements Calculator {

    public void add(int a, int b) {
        System.out.println("Addition = " + (a + b));
    }

    public void subtract(int a, int b) {
        System.out.println("Subtraction = " + (a - b));
    }
}

public class Main {
    public static void main(String[] args) {

        SimpleCalc c = new SimpleCalc();

        c.add(20, 10);
        c.subtract(20, 10);
    }
}

const fs = require('fs');

// 1. Create Directory
fs.mkdirSync('MyFolder');

// 2. Create another directory

// 3. List Directories

console.log(files);

// 4. Rename Directory
fs.renameSync('TestFolder', 'NewFolder');
console.log("Directory renamed");

// 5. Delete Directory
